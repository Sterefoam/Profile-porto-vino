# Profile Porto Vino

Ini adalah web portofolio Ryan Alvino, dibangun menggunakan Next.js.

## Menjalankan secara lokal

```bash
npm ci
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser untuk melihat aplikasi.

## Pemeriksaan dan format kode

```bash
npm run lint
npm run typecheck
npm run format
```

Format kode juga berjalan otomatis saat file disimpan di VS Code.
